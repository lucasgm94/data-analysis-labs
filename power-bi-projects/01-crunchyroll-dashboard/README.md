# 🍜 Crunchyroll Analytics Dashboard

## 📊 Overview
An interactive Power BI dashboard built to analyze anime titles, popularity rankings, ratings, and distribution genres based on Crunchyroll data.

---

## 🚀 Key Features
* **Total Titles Tracking:** High-level overview monitoring 3,800+ anime titles.
* **Top Popularity Rankings:** Horizontal bar charts displaying the highest-rated and most popular shows.
* **Score & Release Analysis:** Scatter plots and matrices comparing IMDb and TMDB ratings alongside release years.
* **Interactive Filters:** Dynamic slicers for anime titles, release year ranges, genres, and specific ratings.
